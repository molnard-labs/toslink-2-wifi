# Enclosure

The prototype uses a locally modified version of [ESP32-S3 Protective Enclosure](https://makerworld.com/hu/models/2226235-esp32-s3-protective-enclosure?from=search#profileId-2421557), designed by **Problem fixer** on MakerWorld. The modification adds a cutout for the TOSLINK transmitter.

The original model page identifies its licence as **Standard Digital File License** and states that sharing, hosting or distributing the original or derivatives is prohibited. Accordingly, the modified `.3mf` is not included in this repository and is not covered by the repository's MIT licence. Use the original through its source page and make a permitted local modification, or obtain the original author's permission before distributing a derivative. No separate redistribution permission has been verified.

The local print project is an implementation artifact, not a dimensioned, verified mechanical design. Check the fit of your specific ESP32 board, USB cable, transmitter and optical plug before printing; provide insulation, ventilation and strain relief. The upstream print profile describes PETG, 0.2 mm layers, three walls and 10% infill; those are upstream profile settings, not independently validated requirements for this modification.
